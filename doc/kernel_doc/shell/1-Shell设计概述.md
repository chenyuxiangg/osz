## 概述
Shell模块支持通过上下键选择历史命令；支持通过左右键移动光标；支持在光标处插入字符；支持使用back键删除光标前的字符；支持使用tab键补全命令；支持显示Shell提示词（即“OSZ$”）。通过`SHELL_CB`结构体及其它数据结构配合完成Shell的状态与行为控制。相关文件包括：

- **1-Shell设计概述**：本文件。
- **2-Shell数据结构**：描述所有Shell涉及到的数据结构。
- **3-Shell依赖设计**：描述Shell的上下层依赖关系。
- **4-Shell内存分配设计**：描述Shell对内存使用的设计。
- **5-Shell内部接口设计**：描述Shell模块内使用的接口，均以inner_开头。
- **6-Shell对外接口设计**：描述Shell模块对外暴露的接口，为其它模块提供服务。
- **7-Shell算法与流程设计**：描述Shell模块所有功能特性的逻辑与算法。
- **8-Shell实时性设计**：描述Shell的实时性优化方案。（未完成）
- **9-Shell小型化设计**：描述Shell的小型化优化方案。（未完成）
- **10-Shell错误处理与安全性设计**：描述Shell的鲁棒性设计方案。（未完成）
- **11-Shell可测试性设计**：描述Shell用于测试的相关接口及使用方式。（未完成）
